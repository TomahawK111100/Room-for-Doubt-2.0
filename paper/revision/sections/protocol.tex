\section{Experimental Protocol}
\label{sec:protocol}
\paragraph{Data and base training.}
Each dataset has 50,000 training images and 10,000 clean test images. A fixed seed-42 shuffle divides training images into 45,000 noisy-training and 5,000 noisy-validation samples. Base initialization seeds vary while membership in these sets stays fixed. ResNet50 starts from torchvision ImageNet-1K V2 weights, with inputs resized to $224\times224$. We train for 50 epochs using SGD (learning rate 0.01, momentum 0.9, weight decay $5\times10^{-4}$), cosine annealing, and a global batch size of 128. Base training uses mixed precision on two Tesla T4 GPUs through data parallelism. The first five epochs use cross entropy and later epochs use generalized cross entropy with $q=0.7$. The checkpoint with minimum noisy-validation cross entropy is selected. It is epoch 2 (one-based) for CIFAR-100N seeds 42/43 and CIFAR-10N seeds 42/43, and epoch 3 for CIFAR-100N seed 44. All selected checkpoints are within the cross-entropy warmup.

\paragraph{Meta-training and selection.}
A fixed shuffle with seed 20261015 partitions the 45,000 base-training IDs into 27,000 meta-training, 4,499 meta-validation, 6,751 reserved detector-fit, and 6,750 diagnostic-evaluation IDs. The one-example deviation from a 60/10/15/15 split reflects integer truncation in the saved implementation. The detector-fit partition is unused by this estimator. PCA and regression use only meta-training IDs; the regression checkpoint uses meta-validation targets. These images were nevertheless seen during base training, so held-out regression diagnostics are not equivalent to evaluation on images unseen by the base.

Heads are trained for 25 epochs with Adam, learning rate $10^{-3}$ and batch size 256, using initialization seeds 42, 43, and 44. The two feature sources and all target controls have matched input dimension and head architecture. Clean training labels are accessed only in post-selection annotation-noise diagnostics, not in fitting, descriptor construction, or model selection.

\paragraph{View and temperature selection.}
A shared deterministic stream supplies the original image followed by reflected-padding random crops and horizontal flips at the original CIFAR resolution; each view is then resized and normalized. We search $V\in\{1,5,10\}$ and $T\in\{0.02,0.05,0.1,0.25,0.5,1,2,5,10,10^6\}$ plus exact uniform weighting. Selection maximizes accuracy on the noisy-validation labels. Ties prefer fewer views, then uniform weighting. Each head has its own selected policy; the selected policy table is saved before that run's test evaluation. Base checkpoint and policy selection reuse the same noisy-validation set. This is validation reuse, not an additional independent validation sample.

\paragraph{Metrics and statistical units.}
Accuracy, negative log likelihood (NLL), multiclass Brier score, and expected calibration error (ECE; 15 equal-width confidence bins) are computed from each method's final probabilities. Error AUROC ranks the fixed original-view base errors using the corresponding original-view score; it is not the AUROC of the errors remaining after TTA. The three head-seed results are averaged within each independently trained base. Reported standard deviations describe head initialization only. Paired accuracy intervals use 2,000 multinomial bootstrap draws over test-example correctness differences and the 2.5/97.5 percentiles. They are nominal intervals conditional on the fitted models and policies, without a multiple-comparison correction.

\paragraph{Exploratory scope.}
The completed evidence contains three CIFAR-100N bases (seeds 42, 43, 44) and two CIFAR-10N Worse bases (seeds 42, 43). The additional planned CIFAR-10N seed 44 was deferred by the campaign time-budget admission rule; it has no result and is not included in averages. The test benchmarks have been inspected during method development. Early-5 was selected as the primary target after an initial window study and carried forward into the subsequent runs; this is not a preregistered, untouched-test confirmation. Table entries use FP32 downstream evaluation consistently. The AMP evaluations exported by base training differ from downstream FP32 accuracy by 0.01--0.05 percentage points across these runs and are not mixed into downstream gains. Dataset summaries first average the three heads within each base, then weight independent bases equally; their sample standard deviations describe between-base gain variation, not confidence intervals.
